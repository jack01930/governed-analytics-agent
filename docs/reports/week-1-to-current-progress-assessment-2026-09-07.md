## 4. 哪些“提升”可以成立

### 4.1 真实能力已经扩大

第一、二周 live 都是单次 Text-to-SQL。第二周虽然实现了四类工具，其正式 live 并未调用工具。第三周最新 live 实际记录 120 次模型调用、84 次工具调用和 34 次 Execute，三条归因走通了四个证据阶段。这能支持“受约束的多步分析链路已经落地”。

目前仍是 15 个注册指标和固定 GMV 三维归因范围。Profile Tool 已接入并有测试，但最新 live 的 Profile 调用为 0；这轮不能证明模型具有广泛自主数据探索能力。

### 4.2 测量可信度显著提高

第一周 0 分曾掩盖适配器故障；第三周又暴露出评分器吞掉真实 trace 的问题。现在能区分模型请求、结构输出、计划、SQL 策略、执行、结果契约与评分阶段；失败调用也保留 usage 和成本。六轮迭代均无评分异常，最新账本与模型/工具 trace 逐例一致，116 个历史文件保持不变。

这项提升决定了之后的分数能否用于判断系统质量，而不仅是分数本身上涨。

### 4.3 结果和安全由明确代码规则约束

SQL 强制通过 AST 与只读数据库防线；结果再按类型、别名、NULL、排序和证据引用验证。第三周将“实际发生修复”与“该结果是否符合评测预期”分开，失败结果能如实发布；未用额外重试或清零成本获得表面成功。

生产契约校验与 Oracle 数值评分仍须分开：第三周第四轮迭代的归因结果曾通过形状检查但数值错误。现有字段 `oracle_verified_sufficient` 实际核验证据与查询结果行的对应，不是独立 Oracle 数值正确性证明。

### 4.4 仍不能作出的比较

- 不能把 Week1 的正式 25%、Week2 的 74% 和 Week3 的 94.44% 连成同一条“模型准确率曲线”。它们混合了题目集合、评分规则、任务类型、执行步骤与分母变化。
- Week1 同一次 v2 运行的数值审计为 8/20（40%），原正式分仍为 5/20。与 Week2 最接近的 core-v2 结果 14/20（70%）可以并列，但题面已修改，仍非同题 A/B。
- Week2 安全 20/20 来自本地确定性策略直接验证，没有调用模型；不能解释为模型自主安全能力 100%。
- 最新 Week3 最终候选严格分为 25/26（96.15%），整例分为 34/36（94.44%）；这也不能直接替代 Week2 的 50 题结果分或严格分。
- 当前 heldout 在多轮调试中已查看过，不能再当作未接触的独立泛化验收集。

### 4.5 逐轮可比性核对与缺少的实验

2026-09-07 重新读取六份 Week3 原始 JSON，核对结果如下：

| 比较 | 核对结果 | 可以支持的结论 |
| --- | --- | --- |
| Week1 v1 / v2 | 同 20 题，但 v1 全部停在适配阶段 | 能证明适配链路修复，不能由 0/20 推断原模型 SQL 能力 |
| Week1 / Week2 / Week3 | 题集、题面、分母和执行协议发生变化 | 只能分别报告成绩；当前没有跨周准确率增量结论 |
| Week3 后六轮 | case_ids、overall/known/heldout/executed manifest、协议、请求模型名称、定价和预算配置一致；7bddae6 至 d64d7a8 的评测代码及题集无差异 | 可以描述同一套已知 36 题上的版本回归表现，以及工程修复效果 |
| Week3 34/36 / 未见问题 | 同一题集反复用于诊断，且单版本缺少重复实验 | 不能将 94.44% 当作真实使用成功概率或独立泛化成绩 |

六轮题集 overall manifest 均为 `c0ec7ff77b5927210fdeda1648e32ecc71f3819d6724b0eea5092a262bb4e577`，executed manifest 均为 `c3bcecb5714ac38dcf638969995dd9eb1e2b5bcc619682a2718aa46906785c61`。模型名称相同也不能单独证明服务商内部版本完全固定。Week3 JSON 还未直接绑定 dataset_id，数据复现证明目前依赖外围核验记录，统一对照应补齐该身份字段。

下一项质量评估应建立一份独立于周次的冻结公共基准，并在相同数据快照、题目、Oracle、评分器、模型设置下运行不同系统版本。业务公共子集同时报告各版本的数值正确性、输出契约、任务成功、成本与延迟；归因、澄清和安全等能力子集分别报告。严格保留各版本真实能力边界，不能把新 Agent 的提示词或生成逻辑移植进旧版后仍称其为旧版表现。

调试集与最终验收集必须分开；已查看的 heldout 转作回归集，新的验收题在实现冻结后才使用。对同一版本做预先确定次数的重复运行，逐题配对报告失败变化、波动及不确定性，不挑最好的一次。这些实验完成前，项目可以声称功能与工程能力扩展，暂不能声称跨周准确率提高了多少个百分点。
